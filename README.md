# Well-Beat

**Well-Beat** is a web application for cardiovascular disease prevention and risk prediction.  
It combines the *Framingham (Cuore)* risk model with a dynamic time-series model (*OpenTSLM*) to monitor users’ health over time.

## Stack
- Backend: FastAPI (Python)
- Frontend: Next.js (React)
- Database: PostgreSQL (AWS RDS)
- Hosting: AWS (EC2, S3, CloudFront)
- Version Control: GitHub
